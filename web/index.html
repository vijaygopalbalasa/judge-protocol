Judge Protocol

A neutral, deterministic evaluator for ERC-8183 agent job escrow. When one AI agent hires another and funds escrow, someone must decide whether the delivered work met the agreed criteria. The standard defines that evaluator role but ships no evaluator, so most jobs on Arc testnet let the paying client judge its own job. Judge Protocol fills that seat, and every verdict it has issued so far can be recomputed from public chain data right here in your browser.

Live on-chain state

Verify a verdict yourself

This page holds no secrets. It reads the job from Circle's canonical ERC-8183 contract, finds the provider's own submit() transaction and its on-chain commitment, re-derives every hash locally with an audited keccak256, re-runs the deterministic checks, and compares the result with the signed verdict recorded on chain. If the judge had lied about anything recomputable, a check below would fail. You rely on two things: the chain data (on this site it arrives through a read-only relay at /api/rpc; open ?rpc=direct to read rpc.testnet.arc.io yourself) and this page's code, which is open source in web/ and runs unchanged from a local checkout (python3 -m http.server --directory web).
